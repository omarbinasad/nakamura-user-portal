# Nakamura User Panel

Simple PHP frontend theme structure for Nakamura user panel.

## Run with XAMPP

1. Copy `nakamura-userpanel` into `C:\xampp\htdocs\`
2. Start Apache
3. Open: `http://localhost/nakamura-userpanel/`

## Main files

- `assets/css/style.css` - global variables and main CSS
- `assets/css/responsive.css` - responsive CSS
- `assets/js/main.js` - frontend JavaScript
- `includes/` - reusable PHP parts
- `pages/` - user panel pages
- `login.php` - login page
